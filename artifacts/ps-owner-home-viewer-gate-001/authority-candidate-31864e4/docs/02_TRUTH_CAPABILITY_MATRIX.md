## Required implementation semantics not claimed by the mockups

When implementation is later authorized, every dormant control must use native disabled semantics plus `aria-disabled="true"` where applicable, contribute no form value, expose no active route, perform no pointer or keyboard action, and initiate no backend request. Browser presentation state must never activate a service.
