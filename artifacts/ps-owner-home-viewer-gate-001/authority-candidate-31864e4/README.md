# PS-OWNER-HOME-VIEWER-GATE-001

## Owner Home editable visual reconstruction

Status: **Conditional — In Review**

This package is a visual-design authority candidate reconstructed from native SVG components. It preserves the approved Owner Home composition and cinematic promise while applying the supplied truth, finite-home, and accessibility contracts.

It is not application code. It does not authorize implementation, settle routes, create viewer permissions, deploy anything, or claim a live Owner Home.

## What is editable

- `source/design_system.mjs` contains the shared visual tokens and reusable shell, hero, Capture, audience, content, fixture, and state components.
- `source/generate_all.mjs` composes every review screen from those components.
- Every proposed screen in `exports/` has an editable SVG master and a matching PNG review export.
- Text is live SVG text; UI illustration, icons, controls, cards, borders, focus rings, and state treatments are native vectors. The alpine atmosphere is an independently generated, separately replaceable/croppable image component—not a board crop or UI screenshot.
- The binding authority raster appears only in export 20, the dedicated side-by-side comparison. No proposed Owner Home screen uses it as an underlay or background.
