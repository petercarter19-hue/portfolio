# PS-GOV-001 — Repository Authority, Startup Enforcement, and Owner Translation

## Outcome
Every computer and delivery tool begins from one current repository authority and produces both a rigorous technical record and an understandable owner report with a clear next step.

## Required implementation
- Merge `START_HERE.md`.
- Add mandatory pointer blocks to `AGENTS.md` and `CLAUDE.md`.
- Publish current baseline, current state, and active initiative records.
- Publish startup and completion-report templates.
- Update Bible/Roadmap pointers and guardrail tests.
- Prove the process with a fresh-machine or fresh-session test.

## Completion evidence
A new agent session, given only repository access, can identify the current production baseline, authoritative documents, active package, owner, constraints, and next evidence requirement without a separate verbal handoff from Pete.
