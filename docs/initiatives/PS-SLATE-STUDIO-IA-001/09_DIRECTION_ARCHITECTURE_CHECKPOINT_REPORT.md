The locked desktop concept now has a written plan for how it behaves as a real,
private member experience without pretending the feature has been built.

when a member crosses into today's public Interview Studio, how the page adapts
to small screens and assistive technology, and what the member sees when real
content is loading, empty, denied, or unavailable.

It also defines a deliberately small first build proposal. That proposal is
still waiting for Pete and controlled-governance activation.
