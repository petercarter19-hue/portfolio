## Outcome

PeerSlate moves from a full-package-by-default process to a proportional
delivery model:

1. **Routine** changes use a short brief, focused verification, PR, and a
   compact result.
2. **Bounded feature** changes use a one-page brief and only the specialist
   authority actually triggered by the change.
3. **Protected** changes retain architecture, independent review, Candidate,
   and expanded evidence only for trust, data, publication, consequential AI,
   infrastructure, or material availability risk.

Visual authority is an independent trigger: a material visual-direction change
still needs a named owner-approved authority and visual acceptance. It is not a
reason to impose privacy, migration, or Candidate gates on an otherwise
bounded page change.
