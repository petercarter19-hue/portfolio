## Purpose

Define one coherent future direction for:

- a familiar, finite, work-leading but whole-person Community Feed;
- a distinctive return loop in which posts may receive useful replies,
  author updates, and visible change over time without becoming assignments;
- a post-local, one-row horizontal `Replies & updates` shelf that previews the
  authorized conversation without becoming a timeline or second Feed;
- a finite `Since You Were Here` catch-up experience;
- Spark as an optional, standalone contribution prompt in the desktop return
  rail and mobile Catch up sheet;
- The Break as a separately governed Community destination, with no distributed
  Break placement in the first locked Feed;
- purposeful Community left and right rails with different jobs;
- a mobile composition that preserves those functions without shrinking a
  three-column desktop layout; and
- complete truth, privacy, empty, caught-up, failure, safety, and deferred-state
  requirements before runtime implementation.
