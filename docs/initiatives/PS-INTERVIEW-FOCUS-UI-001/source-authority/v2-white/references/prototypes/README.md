# Static Prototype Notice

These HTML files are frozen visual prototypes.

They may be used to inspect approximate CSS values, spacing, grid proportions, type scale, color relationships, and state composition.

They must **not** be copied into production as-is because they contain static fixture content, presentation-only markup, and no connection to the real PeerSlate routes, state machine, localStorage behavior, endpoints, media lifecycle, accessibility implementation, or tests.

Functional authority always remains the current repository code and passing tests.


The v2.0 prototypes use the approved white/cobalt palette. Their semantic token names are illustrative only; production must map the intent into the repository's existing design-token system. The textarea is the primary input and dictation is optional.
