# Security & privacy

- Only approved public content is rendered: story_data.json and
  resume_data.json are the same sources behind the public My Story and
  résumé pages. Nothing private, no browser-local Slate Board notes.
- No runtime scraping, no client-side fetches to the public site, no new
  endpoints, no database access, no secrets, no hardcoded hostnames.
- Trust lines state only what is true today (private-by-default language
  matches the Bible; no fabricated logos, users, or metrics).
- The voice CTA lands on the clearly-labeled Feed design preview whose page
  states that voice/AI/publish are simulated and nothing is saved.
