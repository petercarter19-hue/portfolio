## Controlled visual language

- one dominant purpose, plane, and work/reading object per destination;
- continuity and governed bands rather than card-space-card composition;
- white/light canvas, near-black ink, forest primary actions, bronze hierarchy,
  restrained plum/aubergine for Voice, and sparing teal/iris identity cues;
- no beige dominance, dark theme, heavy blue wash, colorful post outlines,
  glass, permanent competing rails, or generic stock imagery;
- authentic member-controlled photography; optional imagery collapses;
- editorial titles for emotional/personal transitions and interface typography
  for controls/status/detail;
- local sheets/inspectors attach to a selected object and leave the underlying
  room intact; and
- desktop authority includes real vertical extent; mobile preserves dominant
  content instead of stacking every desktop rail/card.

## Controlled versus illustrative

Controlled: macro composition, continuity, hierarchy, object dominance,
destination identity, owner/viewer separation, color/material roles, contextual
surface behavior, responsive intent, and depicted critical-state purpose.

Illustrative only: names, portraits, generated photographs, copy, dates,
locations, counts, follower/connection state, projects, comments, transcripts,
waveforms, charts, file contents, and unavailable controls. Production uses
authentic, member-authorized data and hides a control whose function is not
released.

Non-material implementation adaptation is permitted for truthful data,
accessibility, localization, responsive reflow, browser/platform behavior,
safe failure, and zero/one/typical/many content—provided it preserves the
visual thesis and is documented. A change to macro layout, dominant object,
page genre, navigation hierarchy, material/color thesis, or major interaction
returns to ChatGPT for revised visual authority and to Pete for acceptance.

Earlier alternatives, historical Profile branches, dark concepts, stock-like
fixture imagery, and unselected owner rails remain evidence only.
