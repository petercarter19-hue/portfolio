## Outcome

Make visual character, surface hierarchy, and tasteful material depth a normal
part of every new or materially revised PeerSlate visual prompt and inspection,
without turning those qualities into a mandatory-effects checklist or a new
delivery gate.

## Scope

- Add one character and materiality pass to the existing visual-integrity
  workflow.
- Define the available depth and atmosphere tools and the taste constraints
  that prevent over-design.
- Record Pete's owner decision in the shared decision log.
- Add a focused governance regression check for the rule and its lean boundary.
- Preserve the existing ChatGPT visual-creation and Pete visual-lock boundary.

## Out of scope

- No route, template, CSS, JavaScript, visual asset, schema, service,
  dependency, feature flag, deployment setting, or live behavior change.
- No page-specific redesign, visual prompt, mockup, implementation, or
  acceptance decision.
- No automatic retrofit or rejection of existing Pete-locked visual authority.
- No separate visual gate, screenshot matrix, effect quota, or audit program.

## Acceptance

1. The standard clearly rejects framework-default or unfinished flatness while
   allowing intentional flatness that serves the page.
2. Depth and texture remain purposeful tools, not required decoration.
3. The rule prevents card soup, false hierarchy, accessibility loss, and
   performance-heavy ornament.
4. The new pass is absorbed into the existing visual round with no duplicate
   artifact, reviewer, or approval step.
5. Existing locked authorities and the ChatGPT-to-Pete creation/lock boundary
   remain unchanged.
6. Focused governance tests fail if the materiality default or its no-new-gate
   protection disappears.
