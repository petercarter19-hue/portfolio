# PS-STORY-COMPOSER-DIRECTION-001 - Member-Owned Story Composition Direction

## Assignment

- Manager and writer: ChatGPT Work

  definition only

## Owner decision

When authenticated members curate My Story, they must be able to move and resize
notes, text, pictures, and other supported Story objects so they can make the
space their own. AI may suggest a layout, but it does not dictate the member's
composition.

Pete's concrete acceptance example is the current **I went back at 36** card:
the future editor must let him shrink or move it so it does not obscure the
sailboat in the Maui photograph.

## Outcome

- Adopt Bible v2.5 and Roadmap v2.4.
- Define direct manipulation plus keyboard/structured alternatives.
- Separate canonical Story content from owner-scoped, versioned layout metadata.
- Keep layout save and Story publication separate and explicit.
- Reserve `PS-STORY-COMPOSER-001` as a future package without activating it.
- Make the decision durable across ChatGPT Work, Codex, Claude, every computer,
  startup pointers, Site Rules, and governance tests.
