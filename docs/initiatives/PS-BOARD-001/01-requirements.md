## Allowed semantic substitutions

Visual fidelity does not authorize mockup-only product semantics. The following
substitutions are required and should preserve the same placement and visual
weight:

| Photo 1 element | PeerSlate implementation |
| --- | --- |
| Mockup navigation/header | Existing real shared PeerSlate header |
| “Executive Planning Wall” | Current approved Slate Board product copy |
| Now | Short Term |
| Next | Projects |
| Ideas | Long Term |
| Blockers | Work |
| Permanent participant roster | Clearly labeled fixture connection preview plus truthful private/save status; never imply live presence |
| Mockup sticky-note content | Generic or clearly identified fixture content |
| Generic voice/magnet icon | Chalk It Up entry into the reviewable capture flow |

Do not copy the mockup's footer or global navigation as inert artwork. Keep the
real application shell. On desktop, the board must still feel like the photo
immediately below that shell.

## Storyboard behavior in Photo 1 language

- Board at rest: Photo 1 composition is fully visible and calm.
- Chalk It Up listening: dim or soften the same board behind a visible capture
  strip; never replace it with a different page style.
- Proposal review: show a contained foreground review surface over the same
  physical board.
- Focus: open contextual depth beside or over the same board and return focus
  to the selected item on close.
- Board/List: List is a semantic equivalent; returning to Board restores the
  Photo 1 composition.

## Rejected visual steering

- A flat indigo/blue product canvas.
- A four-column dashboard or kanban grid.
- A small decorative whiteboard surrounded by cards and metrics.
- Heavy glassmorphism, neon gradients, or pink/coral semantic accents.
- A permanent AI chat or participant panel.
- Pixel-painted canvas text that cannot be selected, reflowed, or read by
  assistive technology.
