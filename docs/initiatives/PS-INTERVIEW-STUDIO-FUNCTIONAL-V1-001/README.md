# PS-INTERVIEW-STUDIO-FUNCTIONAL-V1-001

## Purpose

Deliver the owner-selected public, browser-local Functional V1 for
`/interview-studio` without changing the route, global shell, identity boundary,
provider/model configuration, database, or deployment state.

The bounded outcome is an open-ended practice room with inline local tailoring,
persistent Interview Me, Interview AI, and Video Practice modes, an editable
typed-or-voice transcript, question-family-aware score-free coaching, and
meaningful browser-local history and progress.

## Boundaries

Only these implementation surfaces are authorized:

- `app.py`
- `templates/interview_studio.html`
- `static/css/interview-studio.css`
- `static/js/interview-studio.js`
- `tests/test_interview_studio.py`
- this package folder

The experience remains public and browser-local. It does not add member data,
My Knowledge, Opportunity Slate access, cloud media, automatic transcription,
delivery analysis, schema changes, external retrieval, or deployment.
