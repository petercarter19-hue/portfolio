## Outcome

Prepare one manual, one-use Azure Speech fast-transcription proof using the
existing qualification identity and resources. The synthetic suite targets
10.25 attempted audio hours and fails closed above 10.5 hours across no more
than eight profiles. At the East US promotional rate observed on September 14,
2026, that is approximately $1.025 at target and $1.05 at the ceiling. The
standard-rate ceiling is $3.78. Cost Management and the Microsoft for Startups
portal remain authoritative for actual spend and workload recognition.

This package does not enable scheduled Speech. Both manual-run parameters have
empty defaults, so scheduled qualification runs skip the Speech stage. A later
operator must supply both the exact pinned endpoint and the exact, newly
authorized one-use reference.

## Safety and privacy boundaries

- Use only eight generated fictional profiles. No member, customer, production,
  uploaded, or private content is permitted.
- Preflight the Azure Identity runtime and first Entra token before consuming
  the proof reference.
- Consume the new proof reference with a new durable App Configuration marker,
  and use new proof-specific progress and success markers. Never read, reset,
  overwrite, or reuse an older authorization, attempt, profile, or success
  marker.
- Reserve each profile and its audio duration before the paid provider request.
  Never replay a failed, timed-out, or ambiguous attempt.
- Pin the pathless Speech and App Configuration origins. The Speech adapter
  refuses redirects so multipart audio cannot follow a provider response to a
  second origin. Do not introduce a key, secret, broader role, new resource,
  provider workaround, or endpoint.
- Retain only bounded aggregate metrics. Audio, transcripts, credentials,
  tokens, request identifiers, and provider payloads remain ephemeral.
- App deployment, schema/data mutation, DNS, API Management, advertising, and
  marketing are outside this package.
