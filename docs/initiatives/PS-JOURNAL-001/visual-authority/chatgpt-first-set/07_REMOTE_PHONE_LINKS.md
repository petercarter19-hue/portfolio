## Phone sequence

1. Download the three PNG files above.
2. Start one new ChatGPT Images conversation.
3. Upload the three PNGs in the listed order.
4. Copy/paste file 01 completely.
5. Copy/paste file 02 completely.
6. Generate JOURNAL-01 only.
7. Use file 05 for one targeted correction at a time.
8. After JOURNAL-01 is accepted as the working direction, continue to
   JOURNAL-02, JOURNAL-03, and JOURNAL-04 in the same conversation.

Do not paste the full Bible or Roadmap into this first image conversation. The
relevant controlling instructions are already distilled into file 01.
