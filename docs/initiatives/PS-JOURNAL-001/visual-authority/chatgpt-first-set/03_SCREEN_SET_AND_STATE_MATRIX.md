# Journal Visual Authority — Screen and State Matrix

## Purpose

This matrix prevents an attractive first image from being mistaken for a
complete build authority. The first four screens establish the visual system.
The follow-up rounds close the states required by `PS-JOURNAL-001` and the
Owner Visual Integrity Standard.

## Required Round 2 — Composer states and eligible origins

The same accepted composer and state machine must later be shown from:

- Owner Home;
- Journal;
- My Story;
- Interview Studio; and
- every other origin accepted in the eventual eligible-origin matrix.

Required states:

| State | Required visible truth |
|---|---|
| Closed | Capture a Moment is an action; it consumes no required destination |
| Open/empty | Type and Speak equal; private state; no destination required |
| Composing text | Editable member language; cancel; Save Moment; recovery is truthful |
| Recording | Permission, time/limit, stop/cancel; Type remains available |
| Transcribing | Real processing state; safe exit; no fake transcript |
| Voice review | Authorized playback when retained; editable transcript before Save Moment |
| Saving | Duplicate submission blocked; status announced; no false success |
| Saved | Moment saved privately; Done; optional View in Journal/Use This Moment |
| Enrichment pending | Moment is safe; optional analysis still needs time |
| Enrichment failed | Moment remains safe; retry/dismiss optional analysis |
| Save failed | No claim that the Moment exists; recoverable draft/source and retry explained |
| Stale/conflict | No silent overwrite; changed state and safe reload/merge path explained |
| Permission denied/unavailable | Text fallback remains usable; privacy and data state remain clear |

## Required Round 3 — Owner Journal operating views

The accepted Journal system must later show:

- first/empty Journal;
- first saved Moment appearing immediately;
- multi-year timeline with bounded loading/pagination;
- manage/list view with deterministic search and filters;
- Moment detail with source, accepted version, revisions, relationships,
  audience/publication, uses, and lifecycle;
- edit/version behavior;
- archive and restore;
- export and deletion/deletion-pending behavior;
- missing, restricted, or deleted source/media tombstones;
- curation/presentation controls that do not create a second fact body;
- long Moment text, many years, many items, and slow/partial/error recovery;
- AI, speech, search, or provider unavailable while essential Journal work
  remains useful.

## Required Round 4 — Journal, audience, and My Story distinction

The complete package must later visualize and distinguish:

| Mode | Payload and experience |
|---|---|
| Owner | Complete eligible record, owner controls, sources/versions under policy, private insights where authorized |
| Selected person | Only exact active grant fields; no owner controls, private sources, hidden counts, or private insights |
| Connection | Only active Connection-audience material; access ends on revoke/block/relationship removal |
| Signed-in member | Only material independently permitted for that audience |
| Public | Only explicitly published fields and presentation; no private clues or disabled owner controls |
| My Story | Finite authored narrative using selected governed references and separate layout state; not an activity timeline |

The visual set must show exact audience preview without suggesting that a
private Journal was downloaded and hidden in the browser.

## Cross-form-factor evidence required before implementation

- Desktop at a representative widescreen width.
- Touch mobile at 390px and 320px.
- Narrow-height and landscape behavior where applicable.
- 200% browser zoom/reflow as readable document flow.
- Visible keyboard focus for every primary interaction.
- Screen-reader naming/status/chronology plan.
- Reduced-motion behavior.
- Long content, empty, loading, processing, unavailable, restricted, failure,
  retry, and recovery.
- Exact truth labels for live, private, public, planned, unavailable,
  simulated, stored, transmitted, and not stored behavior.

## Product-copy guardrails

Approved first-round labels:

- Journal
- Private to you
- Capture a Moment
- Timeline
- Manage
- Type
- Speak
- Cancel
- Save Moment
- Moment saved privately
- It is now in your Journal.
- Done
- View in Journal
- Use This Moment

Prohibited or misleading labels for this target architecture:

- Capture as a selected page/tab/room
- Save Capture as the final target action
- Add to Journal
- Publish on save
- Share automatically
- AI-enhanced Moment saved without member review
- Your streak will reset
- Public by default

## Fictional fixture boundary

The first set uses Maya Thompson only as generic fixture data. It must not
encode a specific employer, location, date history, role count, demographic
assumption, or professional level into reusable components. The product must
also work for students, early-career members, career changers, freelancers,
mid-career members, and senior members.
